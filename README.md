# Portfólio Terminal - João Pedro 👨‍💻

Bem-vindo ao meu portfólio pessoal! Este projeto foi desenvolvido com a intenção de criar uma experiência imersiva inspirada em um ambiente de terminal retro/cyberpunk. 

Toda a aplicação simula a sensação de digitar comandos em um sistema operacional via linha de comando, e foi construída com tecnologias web modernas.

## 🚀 Tecnologias Utilizadas

- **React.js** - Biblioteca principal para a construção da interface de usuário.
- **TypeScript** - Tipagem estática para garantir a qualidade e manutenção do código.
- **Vite** - Ferramenta de build rápida e eficiente.
- **CSS3** - Estilização customizada em *Vanilla CSS*, com uso extensivo de variáveis e Flexbox para montar o layout retro e responsivo.

## ⚙️ Funcionalidades

1. **Terminal Interativo**: 
   - Um prompt funcional que aceita comandos reais (experimente digitar `help`).
   - Comandos integrados como `fastfetch` (exibe especificações do sistema fictício), `github` (redireciona para o meu perfil real), `whoami`, `clear`, `date`, entre outros.
2. **Chat de Visitantes (Guestbook)**:
   - Um mural de recados integrado que utiliza o `localStorage` do navegador para armazenar mensagens localmente, mantendo o histórico de interações ativo.
3. **Identidade Dinâmica**:
   - Um painel lateral que carrega dinamicamente as informações do usuário a partir de um arquivo de configuração `JSON`.
   - Sistema de cálculo automatizado de tempo de vida (Uptime), exibindo com precisão anos, meses, semanas e dias desde a minha data de nascimento.
4. **Deploy Otimizado**:
   - Totalmente compatível e configurado para o **GitHub Pages** usando paths relativos no Vite.

## 🛠️ Como rodar o projeto localmente

1. Clone este repositório na sua máquina:
   ```bash
   git clone https://github.com/joaopssx/portfolio-terminal.git
   ```
2. Acesse o diretório do projeto:
   ```bash
   cd portfolio-terminal
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
